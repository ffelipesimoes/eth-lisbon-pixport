# PIXPORT Tester Kit (venue)

**Purpose:** run a 5-step external validation session in ≤10 minutes and capture judge-grade evidence for [VALIDATION.md](../../VALIDATION.md).  
**Audience:** independent builders at ETHGlobal Lisbon (not PIXPORT team).  
**Facilitator:** Felipe / CEO / SubmissionOfficer.

Print this folder or keep it open on a second laptop.

| File | Use |
|------|-----|
| [5-STEP-SCRIPT.md](./5-STEP-SCRIPT.md) | What the tester does (read aloud) |
| [FEEDBACK-FORM.md](./FEEDBACK-FORM.md) | Fill one form per tester (copy into VALIDATION.md same day) |
| [CONSENT.md](./CONSENT.md) | One-line quote consent |
| [FACILITATOR-CHEATSHEET.md](./FACILITATOR-CHEATSHEET.md) | Setup, recovery, HashScan links |

---

## 60-second pitch to recruit a tester

> "We're PIXPORT — on-chain mandates for Pix on Hedera, zero Solidity.  
> Can I borrow 8 minutes? You'll open one HashScan RECUSA tx, click through our demo, and give one honest sentence we can quote in the submission. First name + project name only."

If no: thank them, log in VALIDATION recruiting table, move on.  
If yes: consent → 5 steps → form → photo optional → done.

## Success criteria for the kit

- [ ] ≥3 completed [FEEDBACK-FORM.md](./FEEDBACK-FORM.md) from non-team people  
- [ ] Each form has verbatim quote + PASS / PASS_WITH_FRICTION / FAIL  
- [ ] ≥1 tester opened the **RECUSA** HashScan link themselves  
- [ ] Forms transcribed into root [VALIDATION.md](../../VALIDATION.md) same day
